# Contact form

Recipient: mia@mothermother.org
Subject: MOTHERMOTHER.ORG INQUIRY
Provider: FormSubmit (https://formsubmit.co/documentation)

Before launch, submit the form from the hosted site or a local HTTP preview (not a file:// page). FormSubmit emails an activation link to Mia. Mia must click it to enable delivery. Check spam if needed. Then submit a second test and verify the inquiry arrives and Reply addresses the submitter.

The form posts to FormSubmit and uses its confirmation/CAPTCHA page. Default CAPTCHA remains enabled, with an additional honeypot. The service processes the submitted name, email, service and message. The email input supplies Reply-To. No API keys are stored in this static site.

Local configuration and required fields have been checked. No live test message has been sent, and inbox delivery has not been verified.
